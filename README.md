# Ayadee / Peter Edmund Johnson website

## Deploy with GitHub + Vercel

1. Replace the existing `index.html` in the GitHub repository with the included file.
2. Commit the change to the branch connected to Vercel.
3. Vercel should deploy automatically.
4. In Vercel, add `ayadee.foundation` under **Project → Settings → Domains**.
5. In GoDaddy, remove domain masking and use the DNS records Vercel provides.

The favicon is embedded directly in `index.html`, so no separate image file is required.

Before publishing, verify the email and LinkedIn URL in the Contact section.
